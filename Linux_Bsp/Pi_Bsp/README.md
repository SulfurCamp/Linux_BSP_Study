# Pi_Bsp: Raspberry Pi Board Support Package (BSP) & Device Driver Development

이 폴더는 라즈베리 파이 환경에서 리눅스 디바이스 드라이버 개발 및 관련 사용자 공간 애플리케이션 예제들을 포함합니다. BSP(Board Support Package)의 일환으로, 라즈베리 파이의 하드웨어 기능을 제어하고 리눅스 커널과 상호작용하는 방법을 학습하는 데 중점을 둡니다. 다양한 하드웨어 주변 장치(LED, 키패드, FND 등)를 제어하는 드라이버와 이를 테스트하는 애플리케이션 코드가 포함되어 있습니다.

## 학습 가능한 주요 개념

*   **리눅스 디바이스 드라이버 개발:** 리눅스 커널 모듈(`.ko` 파일) 형태로 디바이스 드라이버를 작성하고 로드하는 방법.
*   **커널-사용자 공간 통신:** `ioctl`, `/proc` 파일 시스템, 블로킹/논블로킹 I/O, 폴링(poll) 등을 이용한 커널 드라이버와 사용자 공간 애플리케이션 간의 데이터 교환 및 제어.
*   **하드웨어 제어:** GPIO(General Purpose Input/Output)를 이용한 LED, 키패드, FND 등 주변 장치 제어.
*   **커널 타이머:** 커널 내에서 주기적인 작업을 수행하기 위한 타이머 사용.
*   **인터럽트 처리:** 하드웨어 인터럽트를 이용한 비동기 이벤트 처리.
*   **리눅스 커널 컴파일 및 포팅:** `zImage` 파일 존재로 미루어 보아, 커널 컴파일 및 라즈베리 파이 보드에 포팅하는 과정도 포함될 수 있습니다.
*   **Qt 프레임워크:** `Qt` 폴더 존재로 미루어 보아, Qt를 이용한 GUI 애플리케이션 개발도 포함될 수 있습니다.

## 폴더 구조 및 주요 파일 설명

*   **`bsp/`**: 보드 지원 패키지 관련 파일 또는 빌드 스크립트가 포함될 수 있습니다.
*   **`Qt/`**: Qt 프레임워크를 사용하여 개발된 GUI 애플리케이션 관련 소스 코드 또는 프로젝트 파일.
*   **`.ko` 파일 (커널 모듈):**
    *   `call_dev.ko`, `call_ledkey_dev.ko`: 특정 디바이스 또는 LED/키패드 관련 드라이버.
    *   `fnd_dev.ko`: FND(Flexible Numeric Display) 제어 드라이버.
    *   `hello.ko`: 기본적인 "Hello World" 커널 모듈 예제.
    *   `ioctl_dev.ko`: `ioctl` 시스템 호출을 사용하여 사용자 공간과 통신하는 드라이버.
    *   `kerneltimer_dev.ko`, `kerneltimer.ko`, `kerneltimer_led.ko`: 리눅스 커널 타이머를 활용한 드라이버.
    *   `led.ko`: LED 제어 드라이버.
    *   `ledkey_blockio_dev.ko`: 블로킹 I/O를 사용하는 LED/키패드 드라이버.
    *   `ledkey_int_dev.ko`: 인터럽트 기반 LED/키패드 드라이버.
    *   `ledkey_param.ko`: 파라미터를 전달받는 LED/키패드 드라이버.
    *   `ledkey_poll_dev.ko`: 폴링(poll) 메커니즘을 사용하는 LED/키패드 드라이버.
    *   `minor_dev.ko`: 마이너 디바이스 번호 할당과 관련된 드라이버.
    *   `p527_ledkey_dev.ko`: 특정 페이지(p527)의 LED/키패드 드라이버.
*   **`.app` 파일 (사용자 공간 애플리케이션):**
    *   `call_app`, `call_ledkey_app`, `call_ledkey_app_ox`: 해당 드라이버를 테스트하거나 제어하는 사용자 공간 프로그램.
    *   `fnd_app`: FND 드라이버를 테스트하는 애플리케이션.
    *   `ioctl_app`: `ioctl_dev.ko` 드라이버와 통신하는 애플리케이션.
    *   `kerneltimer_app`: 커널 타이머 드라이버를 테스트하는 애플리케이션.
    *   `ledkey_blockio_app`, `ledkey_int_app`, `ledkey_poll_app`: 해당 드라이버를 테스트하는 애플리케이션.
    *   `minor_app`: 마이너 디바이스 드라이버를 테스트하는 애플리케이션.
    *   `proc_test_app`: `/proc` 파일 시스템 관련 테스트 애플리케이션.
*   **`mount.sh`**: 파일 시스템 마운트와 관련된 쉘 스크립트.
*   **`tetrixPi.tar`**: 테트릭스 파이 관련 아카이브 파일.
*   **`zImage`**: 라즈베리 파이용 리눅스 커널 이미지 파일.

## 빌드 및 실행 방법 (일반적인 절차)

1.  **커널 모듈 빌드:** 각 드라이버의 소스 코드(일반적으로 `.c` 파일)를 컴파일하여 `.ko` 파일을 생성합니다. 이를 위해서는 리눅스 커널 소스 코드와 빌드 환경이 필요합니다.
    ```bash
    # 드라이버 소스 디렉토리로 이동
    make
    ```
2.  **커널 모듈 로드:** 생성된 `.ko` 파일을 `insmod` 명령어를 사용하여 커널에 로드합니다.
    ```bash
    sudo insmod <드라이버_이름>.ko
    ```
3.  **디바이스 노드 생성:** 드라이버가 `/dev` 디렉토리에 디바이스 노드를 생성하지 않는 경우, `mknod` 명령어를 사용하여 수동으로 생성해야 할 수 있습니다.
    ```bash
    sudo mknod /dev/<디바이스_이름> c <메이저_번호> <마이너_번호>
    ```
4.  **애플리케이션 컴파일 및 실행:** 사용자 공간 애플리케이션(`.app` 파일)을 컴파일하고 실행하여 드라이버의 기능을 테스트합니다.
    ```bash
    gcc -o <애플리케이션_이름> <애플리케이션_소스>.c
    ./<애플리케이션_이름>
    ```
5.  **커널 모듈 언로드:** 테스트가 끝나면 `rmmod` 명령어를 사용하여 드라이버를 언로드합니다.
    ```bash
    sudo rmmod <드라이버_이름>
    ```

## 참고

이 폴더의 예제들은 라즈베리 파이의 특정 하드웨어 구성 및 리눅스 커널 버전에 따라 동작 방식이 달라질 수 있습니다. 각 예제에 대한 상세한 설명은 해당 소스 코드 내의 주석이나 별도의 문서에서 찾아볼 수 있습니다.
