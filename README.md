# Linux Board Support Package (BSP) & Device Drivers

이 폴더는 리눅스 기반 시스템의 Board Support Package (BSP) 및 디바이스 드라이버 관련 예제 및 학습 자료를 포함합니다. BSP는 특정 하드웨어 보드에서 운영체제(리눅스)가 원활하게 동작하도록 지원하는 소프트웨어 집합이며, 주로 디바이스 드라이버 개발과 밀접하게 관련되어 있습니다.

## 학습 가능한 주요 개념

*   **Board Support Package (BSP):** 특정 하드웨어 플랫폼에 리눅스를 포팅하고 최적화하는 과정.
*   **리눅스 디바이스 드라이버:** 리눅스 커널에서 하드웨어 장치를 제어하기 위한 드라이버 개발.
*   **커널 모듈:** 리눅스 커널에 동적으로 로드 및 언로드될 수 있는 코드 작성.
*   **하드웨어 인터페이스:** GPIO, SPI, I2C, UART 등 다양한 하드웨어 인터페이스 제어.
*   **커널 컴파일 및 모듈 빌드:** 리눅스 커널 소스 코드 관리 및 커널 모듈 빌드 시스템 이해.
*   **임베디드 리눅스 시스템:** 라즈베리 파이와 같은 임베디드 보드에서의 리눅스 활용.

## 폴더 구조 및 내용

이 폴더는 `Pi_Bsp`와 `Ubuntu_BSP`와 같은 서브 폴더를 포함하며, 각 서브 폴더는 특정 플랫폼(라즈베리 파이, 우분투)에 특화된 BSP 또는 디바이스 드라이버 예제를 담고 있습니다. 일반적으로 다음과 같은 파일들을 포함할 수 있습니다:

*   **디바이스 드라이버 소스 코드:** `.c`, `.h` 파일 (예: 문자 디바이스 드라이버, 플랫폼 드라이버).
*   **Makefile:** 커널 모듈 또는 드라이버를 빌드하기 위한 스크립트.
*   **커널 설정 파일:** `.config` 또는 관련 설정 파일.
*   **디바이스 트리 소스 (DTS):** 하드웨어 정보를 커널에 전달하는 파일 (`.dts`, `.dtsi`).
*   **문서 및 학습 자료:** 드라이버 개발 관련 설명 문서.

## 개발 환경 및 빌드 방법

디바이스 드라이버 개발은 특정 리눅스 커널 버전과 빌드 환경에 의존적입니다. 일반적으로 다음과 같은 단계를 따릅니다:

1.  **리눅스 커널 소스 코드 준비:** 대상 시스템의 커널 소스 코드를 확보합니다.
2.  **크로스 컴파일러 설정 (임베디드 시스템의 경우):** 대상 아키텍처에 맞는 크로스 컴파일러를 설치하고 설정합니다.
3.  **드라이버 컴파일:** 제공된 Makefile을 사용하여 드라이버 소스 코드를 컴파일합니다.
    ```bash
    # 드라이버 소스 폴더로 이동
    make
    ```
4.  **커널 모듈 로드/언로드:** 컴파일된 `.ko` 파일을 `insmod` 명령어로 로드하고, `rmmod` 명령어로 언로드합니다.
    ```bash
    sudo insmod your_driver.ko
    sudo rmmod your_driver
    ```
